# Deep Learning Fundamentals: Keras, PyTorch, and Neural Network Architectures

## 1. Keras

**Keras** is a high-level deep learning API written in Python.  
It simplifies building and training neural networks.

### Key Points
- User-friendly and beginner-friendly
- Runs on top of deep learning frameworks such as:
  - TensorFlow
  - PyTorch (through integrations)
- Supports rapid prototyping
- Provides prebuilt layers, optimizers, and training utilities

### Example Use Cases
- Image classification
- Text processing
- Recommendation systems
- Deep learning research

---

## 2. PyTorch

**PyTorch** is an open-source deep learning framework developed by Meta (Facebook).

### Key Features
- Dynamic computation graphs
- Strong GPU acceleration
- Popular in research and production
- Flexible and pythonic

### Common Uses
- Computer vision
- NLP (Natural Language Processing)
- Reinforcement learning
- Generative AI

---

## 3. CNN (Convolutional Neural Network)

A **CNN** is a specialized neural network architecture mainly designed for visual data such as:
- Images
- Videos

CNNs automatically learn spatial patterns using **convolutional layers**.

---

## Important Clarification

- **Keras** and **PyTorch** are **frameworks/tools**
- **CNN** is a **neural network architecture**

### In Short

| Type | Example |
|---|---|
| Framework / Library | Keras, PyTorch, TensorFlow |
| Neural Network Architecture | CNN, RNN, Transformer |

---

# Major Deep Learning Architectures

## Core Neural Network Architectures

| Architecture | Best For | Key Mechanism |
|---|---|---|
| **CNN (Convolutional Neural Network)** | Images, video | Convolutional filters detect spatial features |
| **RNN (Recurrent Neural Network)** | Sequences, time series | Hidden state maintained across time steps |
| **LSTM (Long Short-Term Memory)** | Long sequences, text | Gated cells solve vanishing gradient problem |
| **GRU (Gated Recurrent Unit)** | Sequence tasks | Lightweight gating mechanism |
| **Transformer** | NLP, sequences, vision | Self-attention mechanism |
| **MLP (Multi-Layer Perceptron)** | Tabular data, simple prediction | Fully connected layers |

---

# Advanced Deep Learning Architectures

| Architecture | Best For | Notable Feature |
|---|---|---|
| **GAN (Generative Adversarial Network)** | Generating realistic data | Generator vs discriminator competition |
| **Autoencoder** | Compression, denoising | Encoder-decoder representation learning |
| **VAE (Variational Autoencoder)** | Generative modeling | Probabilistic latent representation |
| **U-Net** | Medical image segmentation | Skip connections with encoder-decoder design |
| **ResNet (Residual Network)** | Very deep neural networks | Residual/skip connections |
| **DenseNet** | Image classification | Dense inter-layer connectivity |
| **Inception Network** | Image classification | Parallel multi-scale convolutions |
| **YOLO (You Only Look Once)** | Real-time object detection | Single-pass object detection |
| **Siamese Network** | Similarity learning | Shared-weight twin networks |
| **Capsule Network** | Spatial relationships in images | Capsules preserve pose information |
| **Graph Neural Network (GNN)** | Graph-structured data | Operates on nodes and edges |
| **NeRF (Neural Radiance Field)** | 3D scene reconstruction | Neural rendering of 3D scenes |
| **Diffusion Models** | AI image generation | Progressive denoising process |

# Summary

- **Keras** → High-level deep learning API
- **PyTorch** → Deep learning framework
- **CNN** → Neural network architecture for images
- Architectures define **how networks are structured**
- Frameworks provide tools to **implement architectures**
